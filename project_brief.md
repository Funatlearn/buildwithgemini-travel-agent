# My agent: travel-agent
One-liner: A conversational agent that helps travelers discover destinations and plan custom trips with a catalog of accommodations, attractions, and curated daily itineraries.

Tool coverage:
- Memory: User travel preferences, budget tiers, dietary restrictions, past visited cities, and favorite travel styles (e.g., adventure vs. relaxation).
- Tools: Look up destinations, search attractions & accommodations, check local weather, and book/save itinerary items.
- Catalog/UI: Curated hotel/stay cards, attraction highlights, and day-by-day itinerary schedule tables.
- Image gen: Photorealistic preview postcards of suggested destinations and custom itinerary landmarks.
- Sandbox: Trip budget calculations, currency conversions, and travel route time/expense estimations.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for trip budget/expense calculations, Google Maps API integration, Cloud Trace for latency tracking
